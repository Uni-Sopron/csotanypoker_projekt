# Csotanypoker_projekt  

## Telepítés: 
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt

## src mappába belépés:
    cd src

## Futtatás:
**1.  Szerver indítás:**   
    python -m csotanypoker.server.main  

**2. Kliens inditás:**  
    python -m csotanypoker.client.client
